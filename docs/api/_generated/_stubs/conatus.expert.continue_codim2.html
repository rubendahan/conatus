conatus.expert.continue_codim2¶

conatus.expert.continue_codim2(system, x0, kind, parameters, settings, *, par=None, omega=None, direction=1.0, bounds=None, tests=None)[source]¶

Continue a fold (kind="fold") or Hopf (kind="hopf") point in two parameters.

x0: the located point (event of continue_equilibria); par its parameter values; omega: Hopf frequency (default: pair closest to the axis). direction orients the start along +p2. tests default: all tests of the curve kind.

Parameters:

  • system (DynamicalSystem)

  • x0 (ndarray)

  • kind (str)

  • parameters (tuple[str, str])

  • settings (ContinuationSettings)

  • par (Mapping[str, float] | None)

  • omega (float | None)

  • direction (float)

  • bounds (Mapping[str, tuple[float, float]] | None)

  • tests (tuple[str, ...] | None)

Return type:

Curve
