A first eigenvalue problem: Orr–Sommerfeld¶

Goal. Compute the least stable mode of plane Poiseuille flow at \(Re = 10^4\), \(\alpha = 1\), and the critical Reynolds number, with a residual for every number. Expected. \(c = 0.23752649 + 0.00373967\,i\) and \(Re_c = 5772.22\), \(\alpha_c = 1.02056\) (Orszag 1971, J. Fluid Mech. 50, 689). Time: under a minute on one CPU core. Script: t01_orr_sommerfeld.py.

The equation¶

For a normal mode \(v(y)\,e^{i\alpha(x - ct)}\) of the wall-normal velocity, with \(U = 1 - y^2\) and \(\mathcal{L}_2 = D^2 - \alpha^2\),

\[ \frac{1}{i\alpha Re}\,\mathcal{L}_2^2 v - U\,\mathcal{L}_2 v + U'' v + c\,\mathcal{L}_2 v = 0, \qquad v = v' = 0 \ \text{at}\ y = \pm 1 . \]

The eigenvalue \(c\) appears linearly; Conatus reads the mass matrix off its coefficient.

Write the problem¶

import conatus as cn
from conatus.expert import critical, verify

line = cn.Box(y=cn.walls(-1, 1))               # wall-normal coordinate y in [-1, 1]
m = cn.Model(line, name="Orr-Sommerfeld", Re=1e4, alpha=1.0)
m.scalar("v")                                  # v(y) exp(i alpha (x - c t)), wall-normal velocity
m.given(U=lambda y: 1 - y**2)                  # plane Poiseuille base flow (depends on y)
m.eigenvalue("c", growth="imag")               # wave speed c: a mode grows with Im c
m.define("L2(f) = dy(dy(f)) - alpha**2*f")     # D^2 - alpha^2
m.equations("Orr_Sommerfeld: L2(L2(v))/(1j*alpha*Re) - U*L2(v) + dy(dy(U))*v + c*L2(v) = 0")
m.at("walls", "v = 0", "dy(v) = 0")            # rigid walls at y = -1 and y = 1
print(m.explain(full=True))                    # every automatic decision (taus, modes)

Things to notice:

  • The model declares the geometry and the equations. The native compiler chooses the bases and the tau terms when you give N at the solve (N=64).

  • cn.Box(y=cn.walls(-1, 1)) names the geometry, and m.given(U=lambda y: 1 - y**2) the base flow (its argument names say it depends on \(y\) only). m.eigenvalue("c", growth="imag") declares the eigenvalue and how a mode grows. For a phase speed the mode is \(e^{i\alpha(x - ct)}\), so its temporal growth rate is \(\alpha \operatorname{Im} c\); with \(\alpha > 0\), as here, the sign of growth is the sign of \(\operatorname{Im} c\) (growth="real" is for \(e^{st}\)). m.define names the operator \(\mathcal{L}_2\).

  • m.at("walls", "v = 0", "dy(v) = 0") gives four conditions; each tau is placed by a fixed rule (in the equation where \(v\) has its highest order, modes \(N-1, \dots, N-4\)) and m.explain(full=True) prints them (m.explain() is the short summary). The matrices are bit-identical to the hand-written IR version (expert/t01_orr_sommerfeld.py, add_bc), which the test suite checks.

Solve and reject spurious modes¶

res = m.eigenvalues(N=64, drift=96, drift_tol=1e-6)   # keep modes found again at N = 96
i = int(res.values.imag.argmax())                     # least stable surviving mode
print(res.explain(key="imag"))
print(f"c = {res.values[i]:.10f}   backward residual {res.residuals[i]:.1e}")

The tau method produces spurious eigenvalues with huge \(|c|\). The drift filter compares eigenvalues at two resolutions: drift=96 (i.e. drift_plan=) solves the same problem at a finer resolution and keeps only the modes that reappear within drift_tol. A mode set aside is not converged by this test: it may be a tau mode or a physical mode that \(N = 64\) does not resolve. The dense solver also classifies eigenvalues as finite or infinite, with a separate threshold. res.explain() says how many modes were removed and why. Each kept mode carries its backward residual \(\|(L + cM)x\|\) and its drift.

Plot the eigenfunction¶

mode = res.mode(i)                             # the eigenfunction on the grid, taus left out
print(mode.explain())                          # unknowns, grid, declared normalisation
y, v = mode.coordinate("y"), mode["v"]         # Chebyshev points, complex v(y)

res.mode(i) unpacks the eigenvector into the named unknowns on the physical grid: the tau variables are left out, mode["v"] holds the complex values \(v(y_j)\) at the Chebyshev points mode.coordinate("y"), and mode.coeffs("v") the Chebyshev coefficients. An eigenvector is only defined up to a complex factor, so the normalisation is declared and printed by mode.explain(): the first unknown has \(\max|v| = 1\), real and positive where \(|v|\) is largest (here the centre of the channel). The physical perturbation is \(\operatorname{Re}[v(y)\,e^{i\alpha(x - ct)}]\).

Critical Reynolds number, sensitivity, verification¶

# L(Re, alpha) + c M(Re, alpha), exact in the parameters; the same pencil at N = 96 rejects the
# spurious tau modes (drift test, as for eigenvalues above); growth = Im c (the phase speed c)
P = m.parametric(N=64, over=("Re", "alpha"), drift=96, drift_tol=1e-6)
least = P.least_stable(Re=1e4, alpha=1.0)
crit = critical(P, "Re", bracket=(5000, 7000), over={"alpha": (0.98, 1.06)}, xtol=1e-9)
print(crit.explain())                          # growth convention, drift counts, verification
print(f"Re_c = {crit.value:.4f}   alpha_c = {crit.over['alpha']:.6f}")
print(f"dc/dRe = {P.sensitivity(least, 'Re'):.3e}")
print(verify(P, crit.mode, crit).explain())  # residuals, spectral tail, Taylor tests

ParametricEVP builds \(L(Re, \alpha)\) and \(M(Re, \alpha)\) once, as Laurent polynomials in the parameters reconstructed from plans at a few parameter values. P.explain() reports the reconstruction error and the coefficient entries discarded at rounding level. drift=96 builds the same pencil at \(N = 96\). As for eigenvalues(drift=), only the modes found again there within drift_tol are candidates, so the spurious tau modes are not selected. A mode grows when \(\alpha \operatorname{Im} c > 0\), which for \(\alpha > 0\) means \(\operatorname{Im} c > 0\): critical and least_stable read this off the declared eigenvalue (m.eigenvalue("c", growth="imag")) and print it in crit.explain(). critical follows the least stable mode by bordered Newton to \(\operatorname{Im} c = 0\) and minimises over \(\alpha\); a call that leaves out a parameter of the pencil uses the value declared in the model (logged). P.sensitivity gives \(\partial c / \partial Re\) from the left and right eigenvectors (no finite differences). verify then reports residuals, the spectral tail of the eigenvector (is \(N = 64\) enough?) and Taylor tests of the parameter derivatives. A bracket in which the growth does not change sign is refused with the growth at both ends and a suggested bracket.

Check against the reference¶

Check. \(c = 0.2375264888 + 0.0037396706\,i\) with backward residual \(4\times10^{-16}\), equal to Orszag’s \(0.23752649 + 0.00373967\,i\) to all eight published digits; \(Re_c = 5772.2218\) (Orszag: 5772.22), \(\alpha_c = 1.020547\) (Orszag: 1.02056).

C_ORSZAG = 0.23752649 + 0.00373967j          # Orszag (1971), Re = 1e4, alpha = 1
RE_C, ALPHA_C = 5772.22, 1.02056             # Orszag (1971); accurate value 1.020547
assert abs(res.values[i] - C_ORSZAG) < 1e-8, res.values[i]
assert res.residuals[i] < 1e-12
assert abs(abs(v).max() - 1) < 1e-14 and abs(v[0]) < 1e-3 and abs(v[-1]) < 1e-3   # normalised, v = 0 at the walls
assert abs(crit.value - RE_C) < 0.01 and abs(crit.over["alpha"] - ALPHA_C) < 2e-5
print("OK: c and Re_c agree with Orszag (1971) to the published digits; alpha_c within 2e-5")
